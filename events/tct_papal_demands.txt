# Unified List of Papal Demands (Coronation / Anointment)

# # Material / Prestige

# # Gold Payment – The Pope requests gold from the ruler.
# # Why: More likely if the ruler is wealthy or higher tier. Vassals or greedy rulers increase likelihood.
# # Timing: Immediate
# # Base Weight: 20

# # Prestige Sacrifice – The ruler must lose prestige to show humility.
# # Why: Chosen if the Pope wants to reinforce Church authority over the ruler or if the ruler is proud or ambitious.
# # Timing: Immediate
# # Base Weight: 10

# # Artifact Transfer – A Christian relic or artifact must be given to the Pope.
# # Why: Triggered if the ruler owns rare or valuable Christian artifacts.
# # Timing: Immediate
# # Base Weight: 15

# # Religious / Clerical

# # Vow of Celibacy – The ruler or heir must take vows of celibacy.
# # Why: Chosen for rulers without strong heirs or if the Pope wants to influence succession indirectly.
# # Timing: Immediate
# # Base Weight: 5

# # Switch to Papal Investiture – Pope enforces Papal Investiture if free investiture is in use.
# # Why: More likely if the ruler currently practices free investiture. Less likely if ruler is an emperor or strong king.
# # Timing: Immediate
# # Base Weight: 30

# # Give Land to Holy Orders – A duchy or county is granted to an existing Holy Order.
# # Why: Triggered if Holy Orders exist and the ruler has spare land to give. More likely if ruler is at least duke-level.
# # Timing: Immediate
# # Base Weight: 5

# # Political / Territorial

# # Donation of Constantine / Return Italian Lands – The Pope demands restoration of de jure Papal lands (Latium, Romagna, Spoleto, etc.).
# # Why: Chosen if the Papacy does not control its historical holdings. Less likely if the Pope already controls them.
# # Timing: Immediate
# # Base Weight: 20

# # Transfer of Vassal – Pope demands an Italian vassal be transferred under Papal control.
# # Why: More likely if the ruler holds Italian vassals, especially those historically connected to the Papacy.
# # Timing: Immediate
# # Base Weight: 15

# # Recognition of Papal Independence – If the Pope is a vassal, he demands freedom.
# # Why: Always triggered if Pope is a vassal. Less likely if the liege is strong or ruler is weak.
# # Timing: Immediate
# # Base Weight: 80

# # Succession / Dynastic

# # Succession Downgrade – Ruler must switch to a less advantageous succession law.
# # Why: Triggered if the Pope wants to weaken the dynasty’s long-term strength. More likely if ruler has many heirs.
# # Timing: Immediate
# # Base Weight: 10

# # Abdication – Ruler is pressured to step down in favor of an heir.
# # Why: More likely if ruler is old, immoral, or unpopular. The Pope gains influence over the new ruler.
# # Timing: Immediate
# # Base Weight: 10

# # Military / Campaigns

# # Depose an Excommunicated Ruler – Ruler is asked to attack a neighboring excommunicated character.
# # Why: More likely if a target is nearby, independent, and excommunicated. Less likely if target is strong.
# # Timing: Deferred
# # Base Weight: 30

# # Depose an Antipope – Ruler is asked to attack and remove an Antipope.
# # Why: Triggered if antipopes exist within diplomatic range. Less likely if the ruler is too weak.
# # Timing: Deferred
# # Base Weight: 30

# # Crusade or Religious War Support – Ruler is asked to join or lead a war against infidels, heretics, or holders of Papal lands.
# # Why: More likely if ruler is zealous or has a military capability. Less likely if ruler is already at war.
# # Timing: Deferred
# # Base Weight: 30

# # Invade Italian Lands on Pope’s Behalf – Ruler is asked to attack characters controlling de jure Papal territory.
# # Why: Triggered if the Pope lacks historical holdings and potential enemies exist nearby. Less likely if Papacy already controls these lands.
# # Timing: Deferred
# # Base Weight: 30

# # Piety / Personal

# # Go on Pilgrimage – Ruler must complete a pilgrimage before coronation.
# # Why: More likely for rulers with low piety or if Pope wants visible display of devotion.
# # Timing: Deferred
# # Base Weight: 15

# # Public Penance (Immoral Ruler Variant) – Rulers with immoral traits perform penance (e.g., sponsoring church construction).
# # Why: Triggered for gluttonous, drunkard, greedy, or cynical rulers. Less likely for zealous or pious rulers.
# # Timing: Deferred (for building/ritual), Immediate (if simple prestige loss)
# # Base Weight: 10
